# 璇玑网关 v1.1.0 更新说明（2026-08-03）

## ✨ 新增功能

### 1. 最佳思考等级（自动推荐 + 强制覆盖）
- 基于 57 题实测，为各模型预置推荐思考等级（deepseek-v4-flash=high、商汤=low、mimo-v2.5=medium）
- 管理页新增「思考等级」Tab，可自由编辑，支持模型通配符（如 `deepseek-*`）
- 两个开关：「自动设置」= 客户端没传思考等级时自动补推荐值；「强制覆盖」= 不管客户端传啥一律用强制值
- 客户端代码零改动即可用上最优思考等级

### 2. 视频透传开关
- 多模态模型（如 qwen3.6:35b）支持 content 里传 video_url 视频
- 系统设置新增「视频透传」开关，**默认关闭**（视频流量大）；关闭时含 video_url 请求直接返回 400 提示

### 3. 404 路由兜底
- 上游返回 404（模型不存在）时自动路由到其他支持该模型的上游，不再直接把 404 甩给调用者
- 路由前预过滤：不提供该模型的上游直接跳过，避免白跑一次

## 📊 统计与可观测

### 4. 统计排序优化
- 「每上游统计」和「每 API Key 统计」都改为按 **Tokens 使用量**倒序，看谁最耗资源一目了然

### 5. 请求日志新增「API Key」列
- 显示每个请求是哪个 API Key 调用的（名称截断 6 字，悬停看全名），排查各 AI 程序用量更方便

### 6. 缓存命中率修复
- 修复商汤等上游缓存命中率恒显示 100% 的问题（OpenAI 标准字段兼容 + 兜底计算），现在能真实反映命中率

## 🛠 配置与体验

### 7. 系统设置项修复
- 补充 retry.retry_statuses、retry.retry_keywords 等配置项可编辑（之前白名单漏了）
- 清理残留的 server.port 死配置（端口由启动参数决定，改了也没用，已从页面移除）

### 8. 版本号显示
- 管理页显示构建日期（2026-08-03），不再固定 "dev"
- 新增 deploy.sh 一键编译部署脚本

## 🧹 其他
- 管理界面改为单二进制内嵌（web 资源打进二进制，部署更简单）
- 备用网关从 oneapi（117MB）换成自研 xuanji-fallback（18MB），省 ~100MB 内存
