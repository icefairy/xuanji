# 我替你把 3 个免费模型测了 57 道题，然后把最优思考等级写进了网关里

> Go · AI 协议网关 · 最佳思考等级自动注入 · 57 题实测

## 一个反直觉的发现

上个月我测完 DeepSeek V4 Flash、商汤 Lite、mimo-v2.5 三个免费模型。

结果让我挺意外——**每个模型"开多少思考"才最聪明，居然都不一样**：

- **DeepSeek V4 Flash**：`high` 才最优（54/57），`max` 反而掉 1 分——想太多了
- **商汤 Lite**：`low` 才最优（53/57），`medium/high` 代码题还掉分——想太多反而出错
- **mimo-v2.5**：`medium` 才是甜点位（53/57），`high` 玄学题掉分——比商汤还挑

同样的"深度思考"按钮，在 3 个模型里的最优档位差了一个身位。

**更糟的是**：客户端代码里 `reasoning_effort: "high"` 写死的，换商汤模型时直接掉到 52/57——多付了高思考档位的 token，还拿更差的答案。

## 我在网关里做了什么

思路很朴素——**既然每个模型该用哪个等级我有数据，就帮客户端自动用最合适的**。

璇玑网关新增了一个"**最佳思考等级**"功能，分两步：

### 第一步：数据层（`effort_config` 表）

我把实测结果写进数据库：

| 模型 pattern | 推荐值 | 实测得分 |
|------------|--------|---------|
| `deepseek-v4-flash` | `high` | 54/57 (94.7%) |
| `sensenova-*` | `low` | 53/57 (93.0%) |
| `mimo-v2.5` | `medium` | 53/57 (93.0%) |

模型名支持通配符——`deepseek-*` 就能覆盖 flash、pro、max 全家。

### 第二步：转发层（两个开关）

**开关 A：自动设置（推荐）**

客户端没传 `reasoning_effort` 时，网关自动补上推荐值，再走归一化转发。客户端代码一行不用改。

```json
// 客户端发
{"model": "deepseek-v4-flash", "messages": [...]}

// 网关补
{"model": "deepseek-v4-flash", "messages": [...], "reasoning_effort": "high"}

// 转发到上游（DeepSeek 原生支持，透传）
```

**开关 B：强制覆盖**

不管客户端传了什么，一律用配置的强制值替换。适合你确定了最优等级，要让所有客户端都受益。

```json
// 客户端发（写死了 low）
{"model": "mimo-v2.5", "messages": [...], "reasoning_effort": "low"}

// 强制覆盖成 medium
{"model": "mimo-v2.5", "messages": [...], "reasoning_effort": "medium"}
```

### 零侵入的注入逻辑

注入点在请求链的模型映射之后、归一化之前：

```
客户端 body
  → 模型映射（model_mapping 通配 + 一对多）
    → 【新】最佳等级注入（auto / force）
      → 思考深度归一化（各模型族参数转换）
        → 流式 include_usage
          → 上游
```

客户端不传 effort → auto 补 → 归一化生效。客户端传了 effort → force 覆盖 → 归一化生效。客户端不传且 auto 关 → 原样透传。**任何路径都不破坏请求。**

## 57 道题的数据怎么说

题库覆盖中医知识（10）、养生（6）、玄学（8）、生活（6）、逻辑（13）、数学（8）、代码（6）。

最关键的对比——**开启自动推荐 vs 不用**：

| 场景 | 得分 |
|------|------|
| mimo-v2.5 客户端传 `low`（写死） | 52/57 (91.2%) |
| mimo-v2.5 自动推荐（补 `medium`） | **53/57 (93.0%)** |
| 商汤 Lite 客户端传 `low`（碰巧对） | 53/57 (93.0%) |
| 商汤 Lite 客户端传 `high`（过度） | 52/57 (91.2%) |

**光一个自动补值的开关，就能让写死 `low` 的 mimo-v2.5 客户端白捡 1 分。** 更实际的是——你换了新模型，不用改客户端代码，最优等级自动就位。

## 怎么用最方便

1. 打开系统设置，勾上"**自动设置（推荐）**"
2. 在"**思考等级**"Tab 确认预置配置（deepseek-v4-flash=high、商汤=low、mimo-v2.5=medium）
3. 如果测到新模型，加一行配置，推荐值写进去
4. 客户端代码保持不动

**5 分钟，全网关的思考等级最优就位。**
