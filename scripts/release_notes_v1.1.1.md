## v1.1.1

### ✨ 新功能
- **统计页 API Key 模型饼图**：在请求统计页"每 API Key 统计"表中，点击展开行查看该 Key 使用的模型分布饼图，区分不同 AI 程序用量
- **思考等级管理**：独立管理页配置每个模型的最佳 `reasoning_effort` 推荐值，支持模型通配符
- **系统设置页**：统一管理账号安全、思考等级自动推荐/强制覆盖开关、视频透传开关、重试策略（熔断时长/探测间隔/超时/重试状态码/关键词）、渠道优惠时段配置
- **Per-key 冷却队列**：商汤上游成功请求后 1 秒内标记冷却，避免同一 key 被并发打爆触发 429
- **视频透传**：`proxy.video_pass_through` 开关，开启时转发 video_url 给上游（支持 qwen3.6:35b 多模态视频等）
- **上游失败列**：统计页新增"失败"列，显示失败请求数
- **API Key 日志截断**：请求日志页 API Key 名称中文 6 字/英文 12 字符截断
- **v-cloak 防闪烁**：解决 Vue 加载期间模板语法（{{}}、v-for）短暂可见的问题

### 🐛 修复
- 429 限流时不重置索引，按顺序尝试同层其他 key
- 中空 api_key 日志归并到第一个启用 key，历史日志不显示"(未标识)"
- fast_fail_probe_minutes 与 fast_fail_minutes 对齐（均为 5 分钟）
- 新机器 SeedDefaults 升级至 12 项完整配置

### 📊 数据
- 统计总览：每日 Token 趋势折线图
- 每上游：请求数、成功率、延迟、Tokens
- 每 API Key：用量统计 + 模型分布饼图
